# R9 连续首块：相同上下界与显式固定的等价表示诊断

2026-09-22；合成输入，actor 2 的第一轮零目标消息、零乘子、ρ=1。
这是限定四项的开发诊断，不是新分布算法正式实验，不改写原历史状态。

## 预先约定与原件

`rules.toml`在四次优化前写入；源自已冻结的走廊修订批次。
每项求解最多60秒、四项共享600秒。输入、模式、目标和原求解容差保持。
Gurobi两项均显式设置QCPDual=1用于采集对偶，不把该属性差异隐藏。
1775个有限且严格相等的上下界换为显式EqualTo，全部其它约束与目标不变。
无舍入、无新初值、无集中解注入、无放宽A1/A4/KKT和目标报告核对门槛。

`probe.jl`是执行时脚本原字节，`original-model.toml`及各变体的`model.toml`
保存全部原始数值多项式；`witness.toml`保存原变量、原乘子和原状态。
`parent-block.toml`保留父批次首个失败块。科学源码哈希与父清单逐项对应；
仅根Project.toml的测试extras/target曾增加Pkg，运行依赖、compat和锁文件保持。

## 实际结果

四项完成，脚本内部计时27.094352秒；不是端到端性能比较。
Clarabel原表示/固定表示均为ALMOST_OPTIMAL/NEARLY_FEASIBLE_POINT，
因此这项改写没有解除原状态门槛。Gurobi两项均OPTIMAL，原点回代相同，
但报告目标相对误差约5.542e-8，仍超原1e-9记录门槛。

独立多项式回放同时保留原始/对偶/互补/驻点诊断值。
Gurobi乘子的后三类最大指标约2.614e-5、1.288e-3、1.180e-4，
均不能支持原1e-6级KKT接受。Clarabel指标较小也不升级其原生状态。
这些残差采用R3相同归一化形式并补旋转锥；不是A1替代品、全局界或完整子块精度认证。
本诊断不确定求解器内部失真的具体原因，也不证明所有等价表示都无效。
