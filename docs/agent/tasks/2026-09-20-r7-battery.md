## 下一节点的验收重点（计划，尚未实施）

1. 将正常时段入口温度与事件入口温度接成同一给定流量输运过程，由共同正常变量决定事件空间初态。
   不能固定为某次旧调度的最优温度，也不能只传总热库存并自由选择冷热排列。
2. 用同一连续水团回放核对事件前后状态、库存和各空间段温区；通过改变灾前加热时序的手算例，
   检查“相同库存、不同位置”的交付差异是否仍被保留。优化仿射算子与原值回放分别验证。
3. 所有事件和故障共享同一正常启停、电池和空间热状态；恢复可以改变已声明的灾后控制，
   不得为每个事件各自挑选一份更有利的灾前计划。
4. 在相同输入、给定流量和故障集合下比较旧代理规划与详细交付规划，分别报告费用、失供及条件界。
   当前正常控制域的流量/方向/拓扑缺口仍须明确，不将给定流量闭环当作完整正常域。
5. 此连接通过后继续流量选择和完整正常控制域，再做R8资源去除与R9迁移；
