## 实施前推导与固定规则

- 规范形为自由连续变量的`A r ≤ b+Dγ`及非负失供目标`min c'r`；
  变量界全部作为行，故障列与恢复列分开，等式拆为两侧。对偶为`λ≤0, A'λ=c`。
- 失供变量零下界给出共同可行对偶；因此不适用拓扑的不可行LP对应无界对偶，
  不能以完整补救假设将故障排除。PDF119式6-108的恢复见证须单独核对其作用。
- 任一可行失供不超过输入上界B；截断值预先固定为C=B+1 MWh。
  对手饱和于C时上界保持未决/无限，再对候选故障求完整恢复MILP。
- 二值故障与乘子乘积使用原生指示约束；项目不选择乘子大M。
  求解器内部实现和数值容差另有边界，不宣称数值问题被消除。
- 所有建模/内外求解共享600秒截止时间；A1/A2不变，旧API默认行为保持。
- 首先核对规范行与固定故障对偶，再执行指示约束和多支路对照；所有状态按实际结果填写。
