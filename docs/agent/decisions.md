## ADR-002：Julia 闭环与分阶段工具选型（2026-09-16，设计基线）

依据：用户要求按研究主线制定计划、优先 Julia、提供 VS Code 任务，
并允许按需要引入其他库、调研和轻量实现算法。

- 计划与验收分别以 `docs/src/reproduction-plan.md`、`reproduction-acceptance.md` 为准。
- JuMP/MOI 为主建模层，Gurobi 为主求解器；开源交叉验证、统计、作图及自实现范围见 `julia-design.md`。
- 本轮只增加可选 `tools/solvers` 能力预检环境，不改根包依赖，不启动论文模型。
- 自实现优先处理论文算法层；公开算法的原理相似不构成数值等价或全局保证。
- 既有 Python 文献辅助与 PowerShell 原生钩子按边界保留，后续迁移须有独立验收，避免无关重构。
- 研究阈值为运行前基线，后续调整需新决策，不能按结果反向放宽。
- 本轮属于计划和选型，沿用此前暂不提交约定，不触发 Git 阶段合并/发布流程。

## ADR-003：第 2 章详解与首批可核查特例（2026-09-16，实施）

依据：用户明确要求实施 R0+R1 首批计划，并继续暂不提交、不推送。

- 第 2 章完整说明，代码分批。76 个编号公式和原符号表按原页核读；歧义见 C01–C12。
- 原文主符号/希腊字母、语义标签、数组索引；配置与保存键采用有登记的 ASCII 别名。
- z 按原式整个窗口标量；状态显式 0:T、功率1:T；储能补Δt，HS原式单独保留，耦合仅用单位充放效率特例。
- 两节点电网用锥松弛并另验原等式；热网仅取恒定正流节点法，不声称水压或完整PDE已验证。
- 原注入式漏 EB，合成案例显式补入电耗/产热；建筑系数采用带参考步长的离散解释。
- 根环境加入实际使用的 JuMP/CSV/Clarabel/HiGHS；docs 环境 CairoMakie/CSV；Gurobi仍可选。
- 开放求解器穷举两个全窗口储能状态的4种组合；不是论文通用算法的复现。
- 求解器成功与原式残差分开报告；Gurobi默认容差失败后收紧求解参数，保留原失败，不更改A1。
- 人类公式/符号/源码展示从权威清单和当前代码生成；原文资料不进入公开资产。
