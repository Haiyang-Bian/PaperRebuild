# [R2 运行、测试与结果入口](@id ch03-r2)

## 输入与环境

`configs/r2/single-source.toml` 和 `two-source.toml` 是四时段公开合成小例。
时间1h，历史4步；根节点为1；电网阻抗显式标幺，管道单位为SI，主变量为MW/MWh/K/kg/s。
来源与作者数据隔离。生成器 `scripts/create_r2_fixtures.jl --write` 拒绝覆盖既有冻结配置。

根环境有Clarabel，商业求解器在tools/solvers环境，绘图在docs环境。
使用Julia 1.12.6；项目可选本地depot仅影响包缓存，不改变电脑全局Julia版本。

## 从手算到优化与回代

从[WMM手算例](@ref ch03-models)开始，再运行下列命令；均从仓库根目录执行。

```sh
julia +1.12.6 --startup-file=no --project=. scripts/check_ch03.jl
julia +1.12.6 --startup-file=no --project=. test/r2.jl
julia +1.12.6 --startup-file=no --project=. scripts/run_r2.jl single-source wmm_checked_v1 --fixed --open
julia +1.12.6 --startup-file=no --project=tools/solvers scripts/run_r2.jl single-source wmm_checked_v1
julia +1.12.6 --startup-file=no --project=tools/solvers scripts/run_r2.jl two-source schpd_mc_v1
```

`--smoke`为60秒预算；默认开发预算600秒，包含建模和枚举。
`--fixed`锁定配置中的流量，用于同一模型的求解器对照；变流量不能拿它的目标当同模型基准。
`--open`使用Clarabel并枚举主导入流，不能求解一般非凸WMM。
literal版本返回blocked；没有解时不会生成零数组假装成功。

运行输出给出独立目录，保存配置、解、各分支状态、目标/有效界、元数据、代码快照、残差和图源。
原始运行在忽略的 `results/runs/`；经审阅的摘要进入 `results/summaries/r2-first-batch/`。
独立验证和重绘通过R2任务入口选择最近运行或明确提供运行目录，均不重新求解。

## 三层验收

1. **软件与数学：**缺输入、单位/拓扑/历史拒绝；包络角点与盒内检验；无损、稳态、阶跃和变流量输运；
   literal反例；不支持求解器、不可行、超时、落盘重读和篡改拒绝。
2. **同一数学模型：**恒流WMM的Clarabel/Gurobi对照，以及SCHPD枚举/MIP对照，执行A2。
3. **不同模型：**WMM与SCHPD使用同一配置/固定流量设置，分别回代原关系，绘F04和F05。
   不同模型的成本差不是最优间隙；近似模型可能约束自洽但原物理失败。

不追求所有结果显示绿色。水力锥松弛不取等、温度近似偏差和能量代理不一致均为本阶段需要揭示的结果。
论文原始参数缺口未解除时，`paper_match=blocked`保留。
