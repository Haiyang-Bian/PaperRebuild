## 一天才算一个风险样本

假设某天24小时有一次室温越界，这一天的联合事件就是违约。
不能将其中23个未越界小时加进分母，把一次坏日稀释成1/24。
如果求解失败或独立回放不足以判断，该日标为未知，仍在分母中。
备用交付与室温风险是两个检查，求解器返回最优不自动代表二者通过。

[`R6Protocol`](@ref)预先声明2000训练日、500验证日、1000测试日，每日24个一小时时段。
当前生成器是明确标注的合成分布：日云量和小时AR过程产生有界PV比例，
另一AR过程产生带符号调用比例。它们保留日内相关性，每日重新独立抽样。
不是作者原始数据；也没有把现有四时段输入重复六遍当成独立日。

实际设备容量、负荷、温度初值/历史、价格、风险物理温度域和末期条件已在daily-small.toml单独冻结，
所有方法共用；不可根据测试优化结果调整这些输入。数据协议本身只冻结不确定轨迹及统计规则。

## 聚类与参数选择如何避免泄漏？

[`r6_fit_representatives`](@ref)只接受train分组，用预声明尺度比较整条轨迹。
先做确定性Lloyd聚类，再取每簇离中心最近的原始训练日，权重为该簇样本数/2000。
选原始日可以保留每小时上下调用互斥；这是项目补充，不冒称作者使用同样代表选择规则。
聚类失败或空簇不能静默减少100个代表场景。

验证集用于选择预先冻结候选中的风险半径；测试集不能参与距离尺度、聚类、选参或模型修改。
各方法最终使用相同1000日。RO与DRO若仍使用有限支持，只报告该支持上的保证，
它们在新连续轨迹上的表现需要实测，不能由训练优化证书推定。

随机流使用Julia标准库Xoshiro。Julia版本变化可能改变同一种子的数值序列，因此保存全部原值、
分块CSV、协议、源码/环境哈希和聚类记录；种子不能替代原始测试集。
参见[Julia随机数官方文档](https://docs.julialang.org/en/v1/stdlib/Random/#Reproducibility)。

## 怎样解释“95%风险界”？

沿用[验收A5](reproduction-acceptance.md)：上下界分别为单侧95%。
只有保守上界不超过epsilon才支持目标；下界超过epsilon则拒绝；其余保留证据未定。
Clopper–Pearson界用二项尾概率反演，与A5的Beta分位数定义等价；
这是项目统计验收，不是作者已经报告的结论。
方法定义可查[R官方精确二项检验](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/binom.test.html)。

```jldoctest
julia> using PaperRebuild

julia> e = r6_risk_evidence(fill(:pass, 1000); epsilon=0.05);

julia> e["status"]
"supported"

julia> 0 < e["upper"] < 0.0031
true
```

此处是统计手算夹具，**不是实际1000日调度结果**。主要正式风险检验预设为DRJCC联合室温，
其他方法保留比较性区间，不宣称六项同时95%保证。
费用用同轨迹A−B配对自助区间；有缺失配对时报告缺失数量，不删除失败日生成总体排名。
