# [第3章模型：WMM、SCHPD与项目补全](@id ch03-models)

本批是 **R2 小系统模型验证**。作者的完整调度模型与算例尚未得到精确复现。
已有 R1、数据初检和本页的工程测试都不能解除作者原式、输入缺口或物理可行性问题。

## 1. 先认识系统和要优化的量

电网将购电、CHP、光伏与用电负荷连接起来。CHP 同时产电和热，电锅炉/热泵则耗电产热。
热水经过供水管流向负荷，放热后从回水管回到热源。管内已有的热水会让温度变化延迟到达，
这就是本章利用的热网储能；本批没有额外放入电池、热储能罐或建筑温控。

```text
上级电网 → 电节点1 → 电节点2 → 电节点3（双热源小例）
               CHP/EB ↓       CHP/EB ↓
              热源1 ─供水→ 热源2 ─供水→ 负荷3
                    ←回水─       ←回水─
```

决策包括设备出力、购电、支路潮流、温度、质量流率和管内水的历史组成。
目标是运行成本最小；便宜不自动代表物理可行，松弛可能让优化器取得物理上做不到的低成本。

全文57条公式及45个符号记录见[公式与符号索引](@ref ch03-equations)。
机器权威记录为 `docs/reading/ch03/formulas.toml`、`symbols.toml`、`model-issues.toml`。
原式页码按物理PDF46–52/正文29–35登记，不以DOCX文本替代原式证据。

## 3. 设备、电网与水力：沿用哪些约束

CHP采用常热电比，PV实际出力不超过可用量，EB类包含按各自COP配置的电锅炉/热泵。
GT接口保留，主教学案例可用空GT集合。设备发电无功在本批固定为0，由根节点提供系统无功。
CHP热上下界目前由电界与固定热电比导出，尚不支持独立热界；此限制已在式3-4记录。

电网支持有向径向树；输入给出MVA、kV基值和标幺阻抗，功率方程显式换回MW。
根节点电压为1pu。`v`和`ell`分别为幅值平方。式3-12只保证

```math
P_{mn,t}^2+Q_{mn,t}^2\le v_{m,t}\ell_{mn,t}.\tag{R2-1}
```

验证器同时检查原等式，两者不能合成一个通过状态。
水力同样使用式3-26的锥松弛，另算式3-25的等式残差。
没有压力或泵代价促使损耗辅助量取等时，压力松弛可能非常不紧；残差失败必须保留。

**方向补全 R2-C01。** 原式3-17/20/21的符号不能直接同时成立于正温差负荷节点。
代码将 `m_port`、`H_port` 定义成端口正幅值，按热源或负荷角色取净注入符号。
供水混合计管道入流与热源注入；回水混合计反向管道入流与负荷注入。
每条物理管道以固定方向和严格正的流量下界建模；停流、反向流动不在本批范围。

接口：[`load_r2_case`](@ref)、[`build_r2_model`](@ref)。

## 4. WMM：追踪哪些时段的水正在出管

设管内容水质量为 `rho*A*L`。把最近时段的流入水依次填进这个体积：
α描述时段末管内的组成；β从上一时段开始填同样体积，并将当前项设为1。
两者之差乘每段流量，给出本期出管水来自各时段的比例。
式3-28/31使权重呈“若干1、一个分数、若干0”，不需要四舍五入时延。

热损耗需要单独审查。240dpi局部核对显示论文3-34未印出指数底数e和负号，温差括号直接作幂底；
β求和从0起。公开WMM预印本式29使用负指数，β求和从1起，β₀又固定为1。
checked版使用后者，明确记为R2-C02；回水侧采用同样的衰减关系。
2017预印本不是论文所引2019期刊版的已核验替身。
[作者公开预印本与版本记录](https://arxiv.org/abs/1711.02274v2)。

项目WMM停留时间及衰减为

```math
t_{res}=\frac{\Delta t_s}{2}\left(\sum_{s=0}^{T_d}\alpha_s+\sum_{s=1}^{T_d}\beta_s\right),\qquad
\tau^{out}=\tau^{AM}+(\tau^{out*}-\tau^{AM})\exp\left(-\frac{\epsilon t_{res}}{\rho c_w A}\right).\tag{R2-2}
```

`cp_J_kgK=4200` 对应论文 `4.2 kJ/(kg K)`，h转换为秒。
无损输运可以与节点法核对；有损WMM、R1半步核的估计时间不同，不能强制断言相同。

**手算例。** 流量1kg/s、步长1h、管内质量5400kg，延迟1.5步。
四时段入口350/360/350/350K，之前均340K，无损出口应为340/345/355/355K。

```jldoctest
julia> using PaperRebuild

julia> r = replay_water_mass([350.,360.,350.,350.],ones(4),fill(340.,4),ones(4); mass_kg=5400.,dt_h=1.);

julia> r.outlet
4-element Vector{Float64}:
 340.0
 345.0
 355.0
 355.0
```

优化器中的α/β为变量；独立回放器按累计质量逐段填充。
两种实现不是互相调用来“自证正确”。API：[`water_mass_weights`](@ref)、[`replay_water_mass`](@ref)。

## 5. SCHPD：每个简化都留下什么误差

### 热功率包络与 R2-C03

原3-42第二项未见比热系数。以 `cw=4.2`、流量盒[1,4]、温差盒[2,6]为例，
右上角真实乘积热量100.8却超过一条原上界49.6。
项目先对 `w=m*Delta_tau` 建四面包络，再统一乘比热；角点精确，盒内通常只提供区间。
API：[`mccormick_bounds`](@ref)。温差是K，不是时间步。

### 储热代理与 R2-C04

原3-44没有显式时间步且两项都印为供水损耗；3-46/47的体积系数与括号不一致。
取AL=1、初温等于上界，即可得到原初始能量为上界的两倍。
项目逐侧计算体积，J转换MWh，采用

```math
E_t=E_{t-1}+\Delta t_h\left(\sum_jH_{j,t}^{net}-\sum_p(H_{p,t}^{S,loss}+H_{p,t}^{R,loss})\right),\qquad
E_0=\frac{c_w\rho}{3.6\times10^9}\sum_{p,a\in\{S,R\}}A_pL_p(\overline\tau_{p,0}^{a}-\underline\tau^a).\tag{R2-3}
```

初始出口用同一份历史回放到t=0，均温为初始进出口平均；不另造免费初始热量。
终端能量自由，没有额外施加论文未给定的循环条件。
Et仍是简化模型的能量代理，没有强制等于每期温度积分；验证器另报两者的不一致。

### 有限体积动态与 R2-C05、Q10

为恢复式3-52的量纲，项目采用单管有限体积能量式，三项均为W：

```math
\rho A L c_w\frac{\overline\tau_t-\overline\tau_{t-1}}{\Delta t_s}
+c_w m_t(\tau_t^{out}-\tau_t^{in})+\epsilon L(\tau^{loss}_t-\tau_t^{AM})=0.\tag{R2-4}
```

默认 `tau_loss` 是参考温度；dynamic开关使用当期均温。空间只用一个管段平均状态，
这一近似不能完整表达水团的传输时延。
流量乘温差仍是双线性项；`dynamics_product=:mc`增加独立包络，exact则保留该等式。
[`r2_model_class`](@ref)检查实际约束类型，不把论文“已经线性”的文字当作证据。

### 主导入流混合

式3-53至3-57取最大入流那一路的温度，替代真实质量加权均温。
等大流量的不同温度会导致多个可选结果；不以固定排序假装作者规定了唯一解。
整数选择用MIP，开放CI枚举全部小规模选择；M按流量和温度分别推导，不混用单位。

## 6. 验证边界

[`validate_r2_solution`](@ref)从保存解重算模型残差、真实热功率乘积、加权混合、
WMM温度回放、电/水锥松弛原等式及能量温度一致性。
`model_pass`与`original_physics_pass`分开；后者也只覆盖本页列明的补全关系。
不包含泵性能、换热器压降、任意流向、非径向电网或作者全部输入。
阈值继承[验收协议](reproduction-acceptance.md)，近似误差不能用求解器容差抹掉。
