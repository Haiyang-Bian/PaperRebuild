# R6开发实验：六方法已连接，样本外优劣尚未判定

本批在同一个合成24小时物理系统上执行D、SP、RO、DRO、CCP和DRJCC。
六项均得到通过独立模型、市场与风险检查的候选，费用求解状态完成。
这确认了共同日模型、策略报价、内部补救及保存重读的连接；尚未完成正式100代表训练、
500日验证选参或1000日样本外测试，不能把本表当作可靠性排名。

## 冻结输入与证据

- 科学节点：ec4c198；物理模板、数据协议与全部派生输入均先于首次优化冻结。
- 运行目录：`results/runs/r6-training-pilot-v1`；可独立重验的公开见证位于
  `results/summaries/r6-training-pilot-v1`。
- D使用全部2000训练日的平均PV及零调用。其余方法使用冻结排序最先三个训练代表，
  不使用验证或测试日；三个簇原始总质量为0.0395，重新归一化后用于开发模型。
- DRO与DRJCC半径为0.01，CCP与DRJCC风险限额为0.05。这些是预声明开发设置，尚未通过验证集选取。
- 全部设备、历史、外部市场输入、报价范围与物理边界相同；均采用显式乐观市场选择。
  方法定义见[共同模型](r6-methods.md)。

`pilot.toml`保存输入、运行、源码与报告生成器哈希；`witnesses/`保存数值和对应模型。
CSV分别记录费用、成交、情景风险、温度与交付。残差按顺序分块，每块最多5000行，
保留全部数值而不聚合；重验从见证重算后逐字节核对CSV。
新进程重验共38,662条残差全部通过，最大“残差/对应门槛”为3.97904×10⁻⁹；
六方法见证、未优化标记及篡改拒绝共8项检查通过。该数值是已声明约束的数值一致性，
不代表遗漏的物理机制也得到认证。

首次报告因单一残差CSV超过5 MiB发布门槛而失败，原报告保留在本地
`results/runs/r6-pilot-report-failed-ec4c198`。分块只改变证据组织，不重新求解，

## 实际结果

| 方法 | 训练目标，合成USD | 模型/风险检查 | 费用求解状态 |
|---|---:|---|---|
| D | −110.168347 | 通过 | 完成 |
| SP | −85.257164 | 通过 | 完成 |
| RO | −73.719261 | 通过 | 完成 |
| DRO | −83.938028 | 通过 | 完成 |
| CCP | −85.257164 | 通过 | 完成 |
| DRJCC | −83.938028 | 通过 | 完成 |

这些目标使用不同费用规则：D是名义日，SP/CCP是经验期望，RO是支持点最坏费用，
DRO/DRJCC是运输球最坏期望。它们不能直接当作同一批测试日上的平均费用。
负值表示IES市场净支付与内部补救费用之和为负，不能解释为负资源消耗或社会收益。

公开通用验证器把固定舒适开关的D/SP/RO/DRO记录为`declared_fixed_branch`，
CCP/DRJCC记录为`full_optimistic_MPEC`。前者的固定项是各自方法要求的全部舒适开关z=0，
并未固定市场互补分支；本报告保留原有字段，不将证书扩大到允许舒适放松的更大模型。

### 为什么两对方法相同？

三个条件场景概率分别约为0.4051、0.3671和0.2278，均超过0.05。
CCP若放松任意一个完整场景就会超过概率预算，因此必须保持所有z=0。
DRJCC的概率集合包含名义分布，也不能放松任一场景。
于是本批SP与CCP、DRO与DRJCC具有相同可行策略及相同费用规则，目标相等有理论依据。
这不能证明机会约束没有价值，只说明这个开发子集没有让风险预算发挥作用。

### 保守程度改变了什么？

同一三个支持点上，DRO提高了较昂贵场景的权重；RO将费用目标提高到支持点最大值。
结果与这些建模含义一致，但尚不能回答保守方法在未见过的日轨迹上是否更可靠、
其额外费用是否值得，也不能把D的更低名义目标称为优于风险方法。

## 规模与耗时边界

另外仅构建了100代表SP模型：66,082个变量、190,411条约束（含变量界）、432组SOS1，
构建耗时约12.2秒，`optimized=false`。这给出后续预算的实测规模，不是正式训练完成。
开发求解记录约0.16–12.89秒，但首次编译与后续缓存条件不同，
没有形成公平速度实验，不据此声称算法加速或论文规模性能。

## 接下来先做什么？

1. 定义共同的样本外调度规则：固定每个方法的日前成交，在新日轨迹上明确舒适与费用的处理顺序。
   有限训练支持上的情景解不会自动定义新轨迹的操作；测试规则不能随方法或结果临时改变。
2. 冻结正式半径候选、500验证日的选择准则、失败/未知处理及计算预算，执行100代表训练。
3. 锁定参数后只使用1000独立测试日评估费用和联合舒适违约；按A5报告单侧95%概率界，
   未解决日保留在分母中。跨方法费用采用同日配对，缺失时不生成总体排名。
4. 单列持续调用压力实验；实测调用交付与原论文按备用容量计的误差预算分别报告。

当前电网仍为第5章线性电压模型，热网为固定流量输运；补救知道完整未来轨迹，
市场采用显式乐观选择。这些边界与合成数据性质在正式测试中继续保留，
不能由开发检查通过升级为交流、水力、实际市场执行或在线控制保证。
