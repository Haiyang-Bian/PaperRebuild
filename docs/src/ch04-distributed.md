## 2. 为什么两个净注入量不够

当前电网的无功负荷随可调有功负荷变化，热端口约束又分别依赖总产热和总耗热。
例如净热量相同的“产0.2、耗0.1”与“产0.3、耗0.2”，对源/荷质量流率的限制不同。
因此采用如下边界消息：

```math
b_i=(P_i^{net},Q_i^D,H_i^{src},H_i^D),\qquad H_i^{net}=H_i^{src}-H_i^D.
\tag{R4-D1}
```

聚合商持有自身设备、能量状态和不满意度；DSO持有自己的资源、支路、端口以及消息副本。
DSO子问题不优化AG设备。程序串行调度这些独立块，保存全部解供离线研究审计；
这不等于部署了网络通信、访问控制或密码学隐私。

当副本一致时，合并所有块恰好恢复当前集中可行域。费用是各主体真实资源成本之和；
教学支付、服务费在系统福利目标中内部抵消。

## 3. 一致增广项与外层更新

用输入冻结的对角尺度D归一化消息，x为AG边界，z为DSO副本。
成本尺度是最大单时段外部购电费用的容量上界，至少为1合成美元；不是事后最优费用。

```math
\min f(x)+g(z),\quad x=z,\qquad
L_\rho=f(x)+g(z)+\lambda^\mathsf T(x-z)+\frac{\rho}{2}\|x-z\|_2^2.
\tag{R4-D2}
```

f含所有AG成本，g含DSO及外部购能成本，均除以冻结成本尺度。
记u=λ/ρ，则按AG、网络、乘子的顺序更新：

```math
\begin{aligned}
x^{k+1}&\in\arg\min f(x)+\tfrac{\rho}{2}\|x-z^k+u^k\|_2^2,\\
z^{k+1}&\in\arg\min g(z)+\tfrac{\rho}{2}\|x^{k+1}-z+u^k\|_2^2,\\
u^{k+1}&=u^k+x^{k+1}-z^{k+1}.
\end{aligned}
\tag{R4-D3}
```

网络平方项也可写成‖z−x−u‖²，不能写成‖z−x+u‖²。
这个符号差异由同一约束方向导出，解析例和集中对照均验证它。

## 4. 内层双边合同

AG本地副本q_ij向对方出售为正；零售余量仍有明确有限边界。
两方副本需要满足反对称性，不能直接把它们当作物理支路潮流。

```math
P_i^{net}=P_i^{sell}-P_i^{buy}+q_{ij}^P,\qquad
H_i^{net}=H_i^{sell}-H_i^{buy}+q_{ij}^H,\qquad q_{ij}+q_{ji}=0.
\tag{R4-D4}
```

合同按输入功率尺度归一化。给定各方合同q和缩放乘子u_q，
辅助变量是到反对称子空间的欧氏投影：

```math
\begin{aligned}
\widehat q_{ij}^{K+1}&=\tfrac12(q_{ij}^{K+1}+u_{ij}^{K}-q_{ji}^{K+1}-u_{ji}^{K}),\\
\widehat q_{ji}^{K+1}&=-\widehat q_{ij}^{K+1},\\
u_{ij}^{K+1}&=u_{ij}^{K}+q_{ij}^{K+1}-\widehat q_{ij}^{K+1}.
\end{aligned}
\tag{R4-D5}
```

局部合同问题加入ρ_q/2‖q−q̂+u_q‖²。若沿原文λ(q̂−q)的符号定义，
u_q=−λ/ρ_q，这就解释4-69/70乘子差的方向；未缩放λ必须除以ρ_q。

SWM中宽零售通道使任一物理计划都可由零P2P合同表示，合同解可能不唯一。
另运行**AGNB**：保留聚合商零售支出和卖方一次服务费，去掉网络外层，
用同输入集中交易模型检验非零交易。两个目标不可混用费用或上下界。

## 5. 验收与限制

外层原始残差为‖x−z‖∞，对偶残差为ρ‖z^k−z^(k−1)‖∞。
两者≤1e-4是A4条件；内层采用更紧的1e-7。还必须把主体解合并后通过原A1采用模型检查，
否则继续同一迭代或如实记录失败，不暗中集中修正。

固定ρ=ρ_q=1、全零通信初值；最多1000外层，嵌套每次100内层，
独立AGNB最多1000内层。每次完整方法共享600秒，建模、所有重解和验证均计入。
外层与内层复用模型但不依赖其他主体的控制。集中参考始终独立，不能用来初始化。

集中可认证同模型的费用差目标为A4的0.1%；集中自身有效界另按A2的1e-4核验。
局部增广目标的界不构成整体社会费用界。原电网等式残差与采用SOCP分别报告。
有限精度嵌套求解的实验成功，不等同于已经证明所有输入的收敛。

原始/对偶残差的区分也见[ADMM作者示例](https://web.stanford.edu/~boyd/papers/admm/)；
尚未一致的迭代可能比真实最优费用更低，这种轨迹点不是可实施收益。
