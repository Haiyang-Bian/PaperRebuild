## 从纸面到代码

1. 保留主符号大小写：功率 `P/H/Q`，温度 `τ`，效率 `η`，电压平方 `v`，电流平方 `l`。
2. 类别上标转语义标签：``P_t^{\mathrm{BS,ch}}`` → `P_BS_ch[t]`。
3. 变化下标转数组索引：单设备 `[t]`，多设备未来 `[g,t]`；增加设备索引要登记实现扩展。
4. 本批模型返回变量字典，例如 `built.variables["P_CHP"][t]`；局部绑定后可写 `P_CHP[t]`。
   为让 CSV/TOML 跨工具可读，温度保存键用 `tau_*`，科学函数形参用 `τ_*`，映射必须登记。
5. 数学操作写成运算：`V_min_pu^2`，不以装饰性上标冒充平方；转置使用实际转置操作。
6. 不设“大写为参数”规则：作者的 `P` 同时可能是参数或变量，由符号表类别明确区分。
7. `T` 在时间与市场 PTDF 中同形异义；后续 PTDF 用 `T_PTDF`。`v` 在风速与电压平方中不同作用域。
8. 热储能正文 `HS` 与原符号表 `TS` 合并为 `HS` 代码标签，原文别名保留。

## 时间数组与状态边界

功率数组 `1:T` 描述每一段平均功率；储能和建筑状态 `0:T` 描述段边界。
原式 ``E_{t+1}=f(E_t,P_t)`` 在代码写为 `E[t]=f(E[t-1],P[t])`，是整体平移编号，不丢最后一段。
保存为普通向量后，数学边界 `t=0` 在数组位置 1。CSV 单列 `t` 保留数学编号。
初末等式约束整个窗口 `E[T]=E[0]`；建筑没有擅自增加末温回归。
原文 `z^BS/z^HS` 无时间下标，本批按全窗口标量实现；逐时切换需另行确认并命名变体。

## 希腊字母与 ASCII

VS Code Julia 扩展中输入 `\eta` 后按 Tab 得 `η`，`\tau` → `τ`，`\rho` → `ρ`，
`\Delta` → `Δ`，`\epsilon` → `ϵ`。本项目热损耗形参用 `ε`，其 ASCII 配置键为 `epsilon_W_mK`；
不要把不同形的 epsilon 字符当成不同物理量。可从符号表复制标识符，或按 `ascii_alias` 检索。
配置只用 ASCII，例如 `eta_BS_ch`、`tau_initial`。禁止为同一个量随意混用两套 API 名。

## 单位入口

| 原论文/输入 | 统一计算 | 转换 |
| --- | --- | --- |
| kW / kWh | MW / MWh | 除 1000 |
| 百分数效率 | 比值 | 除 100；COP 是热/电比，可超过 1 |
| ℃ | K | 加 273.15；温差数值相同 |
| h | 热管核中的 s | 乘 3600 |
| ``c_w`` 为 kJ/(kg K) | 热功率 MW | `c_w*m*Δτ/1000` |
| ``c_w`` 为 kJ/(kg K) | 衰减核 J/(kg K) | 乘 1000，与 W 制传热系数配合 |
| kV、MVA 基值 | 电网 pu | ``Z_b=V_b^2/S_b`` Ω；``I_b=S_b/(\sqrt3 V_b)`` kA |

三相平衡系统采用总三相功率、线电压基值，支路方程完全在一致标幺制内计算。
`l` 与 `v` 是平方量；恢复实际电流时用 `sqrt(l)*I_base`，恢复电压时用 `sqrt(v)*V_base`。
输入只接受显式统一单位，不“看起来像摄氏度就自动加 273.15”。质量流率 kg/s 与体积流量 m³/s 以密度转换，禁止直接替代。
