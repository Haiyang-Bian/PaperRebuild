# 工作流程与维护节点

| 节点 | 人与 Codex 的操作 | 记录 |
| --- | --- | --- |
| 开始 | 读状态、检查工作区、明确问题和完成/停止条件 | 复杂任务采用独立任务记录 |
| 阅读 | 按页核对，区分原值、估读、引用和补设 | 页码、式号、歧义、下批入口 |
| 实现前 | 确认公式映射、单位、边界和接受阈值 | 映射表、必要决策 |
| 实现后 | 小范围检查、适当测试、修正文档 | 代码、测试、使用说明 |
| 实验后 | 留存输入、环境、命令、状态和输出 | 实验记录和结果摘要，失败也登记 |
| 提交前 | 核对证据，Sync、Check、审阅暂存范围 | 当前状态、受影响手册、提交 |

模板见[记录模板](templates.md)。当前只建立工具链，不自动启动科研实验。

## 自动维护与语义维护

脚本维护文件导航与生成索引；Codex 解释实际变化并更新操作说明和断点。
方法或约束改变时更新规则或决策；普通小修改不重写整本手册。

Stop 比较本轮前后文件及提交位置，发现相关变化最多要求一次收尾。
更新必要文档，通过 Check 后写入绑定当前快照的 Review 凭据。
不能完成时报告缺项，不能用“无影响”掩盖实际变化。

## Git 与发布

关键节点提交代码、配置、记录及验证证据。大数据、完整运行产物和生成网站默认不提交。
推送须获授权；本次基础建设已获公开建仓、首次推送及 Pages 部署授权。

Windows 和 Ubuntu CI 验证工程；只有 `master` 通过检查后部署 `docs/build/`。
Pull Request 不发布网站。科学结论仍须独立验证。
