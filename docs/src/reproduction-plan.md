# 按论文主线推进的复现计划

初始版本：2026-09-16 / v0.1。本页保留复现范围、顺序与验收要求；
早期实施安排是历史快照，不表示所列模型目前仍未实现。
实际结果与尚未完成项见[全文完成清单](reproduction-coverage.md)及各章证据页。
工具预检仍单独记录，不折算为研究进度；本文的原科学要求和阈值没有因已有结果而缩减。

## 1. 怎么使用这份计划

论文主线见[研究解说](thesis-overview.md)，原文疑点见[证据台账](thesis-audit.md)。
本页规定“先做什么、每步交付什么”；数值阈值和科学图表规范以
[验收协议](reproduction-acceptance.md)为准；代码和工具按[Julia 技术设计](julia-design.md)组织。

每一步均走同一条 Julia 流程：**核清输入 → 构建模型 → 求解 → 独立回代检查 →
比较基准 → 生成数据表与图 → 写结论和限制**。失败也形成记录，不能跳过验证直接画图。

两种复现范围必须分别标注：

- **精确输入复现：**模型解释确定，完整输入与作者版本一致，可比较论文数字。
- **方法性验证：**输入经过公开基准替代、自行生成或补充，只能验证算法/物理机制。
  可以继续软件与微型测试，不能用改参数逼近论文目标值。

每阶段报告 `not_started / in_progress / blocked / passed / failed / inconclusive`，
另列 `software / physics / algorithm / paper_match` 四项判定。
文档存在、程序跑完、求解器返回成功，均不能单独使一个研究阶段成为 `passed`。

## 3. R0：把论文变成可执行问题

**操作：**按 PDF 小批次核对第 2、3 章，之后在进入各章前补齐该章契约。

**具体交付：**各章 `equations.csv`、`inputs.toml`、`targets.toml` 和必要决策记录；
字段包括来源哈希、许可、`original / derived / digitized / assumed`、缺失状态。
这里是拟交付文件名，不要求现在创建空文件。

**验收：**引用图表/公式可定位；无同名不同单位的静默合并；没有未经说明的缺省数值。
解释直接影响可行域/最优性时必须有决策依据。
Q01/Q02/Q10 阻断相应第 3 章精确复现，Q06/Q07 阻断第 6 章正式认证。
Q05的概率语义已通过[补事件推导和解析检查](ch05-probability-audit.md)解除采用版阻断；
完整DRJCC调度、Benders和样本外保证仍须分别实现与验收。
阻断期间可以使用明确标为合成的微型系统学习和测试。

**展示：**一张标有设备和节点 ID 的电热拓扑图，以及一张“论文原式—实现组件—验收测试”映射表。

## 4. R1：第 2 章的最小物理闭环

1. **设备：**CHP 可行域、电锅炉/热泵效率、电/热储能的能量状态、建筑温度模型。
   测试零负荷、边界出力、效率、损耗、初值和终端条件；启停/互斥只按论文或明确设备拓扑建立。
2. **电网：**从单节点平衡、两节点支路到径向网络，核对电压、损耗、功率方向和标幺基准。
   用手算微型例比较潮流；对锥松弛单列原等式残差。
3. **热网：**从无损单管道、定流量延迟到供回水网络，核对水力守恒、热功率、混合温度和热损耗。
   热输入阶跃应产生正确的延迟响应；时间步改变时能量积分必须一致。
4. **耦合：**建立 2–3 电节点、1–2 管段、2–4 时段的可手查系统。
   故意构造功率不足、温度超限、储能不足等失败例，确保失败不会被读成零成本成功。

**一般测试：**解析答案、单位转换、缺字段/非法拓扑拒绝、初末状态、可行/不可行状态、保存后重读。
**科学验收：**独立平衡与温度回代通过 A1；能量与成本分项闭合；改变时间步不改变物理单位含义。
**图表：**F01 拓扑，F02 电热设备可行域，F03 热响应与储能状态，F04 各类约束残差。
**停止：**尚未说明初始管温、历史流量或边界时，不用“从零开始”隐式补齐论文条件。

## 5. R2–R3：第 3 章，热网灵活性与快速算法

### R2：先区分模型，再选择求解器

- 按 3.2.1 写 WMM-CHPD，对照原电/水/热网络方程；保留论文已使用的松弛层。
- 按 3.2.2 写 SCHPD，并给每个 McCormick 包络、损耗近似、混合温度近似单独开关和编号。
- 处理 Q10：式（3-52）的双线性项如何消除。若尚不能证明转化为 MISOCP，就将其标为未完成或采用另一个明确命名的变体。
- 小系统上比较“同一模型由不同方法求解”和“不同模型的结果差异”，不要混为一个误差指标。

**测试与验收：**包络在变量盒角点取等、界限内包含原乘积；固定流量时模型正确退化；
原模型回代 A1，原/简化误差分项报告，不能把物理近似产生的值直接当作原问题下界。
**图表：**F05 简化与原模型的温度/热功率误差；F04 残差。

### R3.1：复现 3.3 的求解流程

历史首批按[可行性教程](@ref ch03-r3)推进固定流量SP、弹性诊断及项目直接修正。
其后对偶、灵敏度和投影外层已经实现并开展[独立基线对照](ch03-r3-baseline-results.md)，
保留未满足外层停止和规模性能要求的结果。首批阶段图本身仍不作为F06/F07收敛或速度证据。

SCHPD 初始化 → 固定流量和时延子问题 → 对偶/灵敏度 → 梯度更新与投影 → 不可行修正。
记录每轮流量、步长、目标、子问题状态和原式最大残差。
只从满足前提的连续凸子问题取对偶；对偶符号以解析例和有限差分校核。
跨越时延分段边界时单独检查灵敏度适用性，不能默认端到端自动微分穿透求解器。

**基准：**纯梯度初值对照、论文 NM-CHPD 对照，以及小规模原模型直接求解。
表 3-7 的 NM-CHPD 指向文献 [36]，表注明确采用 Gurobi NonConvex 直接求双线性问题，
不能把 NM 擅自解释成 Nelder–Mead。先追索 [36] 的模型定义；
Optim/BlackBoxOptim 只能作为额外标明的搜索对照，不替代该论文基准。

**验收：**小型可认证模型满足 A2；局部算法报告可行目标、初始化敏感性与停止原因，
只在有有效界时报告最优性差距。梯度可检验区间用多步长差分对照。
迭代到限保留 `budget_exhausted`，不能写成收敛。
**图表：**F06 目标/残差/步长迭代，F07 不同算法耗时—解质量。

## 6. R4：第 4 章，局域交易和分配

### R4.1 集中式参考问题

实现聚合商本地资源、交易量、网络费用与运营商网络调度。
先求集中式总福利基准，再确认聚合商/运营商的分歧点收益。
内部支付必须抵消；核清收益、费用和社会福利的统计口径。

**测试：**双向交易符号、交易守恒、无交易退化、重复记账、网络限额及个体收益计算。
**验收：**A1 和精确基准 A2；福利从独立成本账重算一致。

### R4.2 分布协调与非对称纳什议价

按论文外层 ATC、内层 ADMM 的更新顺序逐步实现，先串行确定性运行。
实现利润分配时分别保留“物理调度”和“支付”输出，核验合作前后收益与预算平衡。
惩罚参数、议价权重、通信轮次、各层容差和超时策略写入配置。

**测试：**2 聚合商解析例、停止条件、缺失子问题解、各主体目标总和、零协同剩余；
凸版本可与集中解比较，含整数/非凸版本必须另行验证，不能套用凸 ADMM 保证。
**论文目标：**4.5 的交易/收益比较、表 4-8 的集中/分布式结果、表 4-9 的规模测试。
**验收：**A1、A2、A4；个体理性和预算平衡均通过，给出残差与集中基准差。
“接近论文差值”和“通过项目算法阈值”分别判定。
**图表：**F10 交易流及网络负载，F11 ATC/ADMM 原始与对偶残差，
F12 合作前后收益/分配，F13 主体数量—时间—质量。
**停止：**集中基准还不可靠、子问题未解、剩余为负而议价未定义时，不宣布分布协同成功。

## 7. R5–R6：第 5 章，备用交付风险

### R5.1 市场与确定性调度

先实现独立市场出清，再实现价格接受者，再处理价格制定者的双层反馈。
逐项对应上层成本/备用收入、下层平衡及价格形成；KKT 化前确认下层连续凸性。
对互补与 Big-M 的上下界给推导或独立优化验证，不能任意给一个很大常数。

**测试：**小市场手算价格，原始出清与 KKT 重构目标/原始可行性/互补残差；
处理多重最优与价格不唯一，不要求所有决策逐项相同。
**验收：**A1–A2；若下层含整数且没有有效替代论证，停止直接套 KKT。
**图表：**F14 能量/备用报价、中标、出清价格及成本分项。

### R5.2 离散概率分布与联合机会约束

依 5.4 明确定义固定情景、经验权重、运输成本、Wasserstein 半径及风险水平。
先对 2–3 情景直接求概率运输 LP，检验半径为零、权重和与最坏概率分布。
先解决 Q05，以“至少一项指定室温约束违约”的补事件核验逻辑。

**测试：**全部达标/单点越界/多点越界、0 和 1 概率、情景排序不变性、非预见性；
增加半径时同一损失向量的最坏期望不应下降。
**验收：**概率与运输约束通过 A1，微型扩展式模型通过 A2。
不把有限支持概率扰动标记为任意连续轨迹保证。

### R5.3 双线性 Benders 与关键场景

先求微型扩展式全情景基准，再分出主问题、补救子问题及最坏分布问题。
核验每个割的方向与适用前提，并将省略情景重新放回检查；失败情景必须重新加入。
保存当前上界、下界、已加入情景、可行性修正及每层状态。

**测试：**可行性割反例、不可补救输入、错误对偶符号、过期/重复割、停机恢复。
**验收：**A2；所有声称为界的量均有有效依据，不能用局部对手解认证最坏风险。
**图表：**F15 半径—成本/备用/最坏概率，F16 Benders 界与活跃情景数。

### R6：冻结模型后进行样本外评估

对照确定性、SP、RO、DRO、CCP、DRJCC；同一数据划分、资源容量、测试轨迹和预算。
场景生成/聚类与半径选择只使用训练/验证部分，最终测试集冻结。
保留原始序列的时间相关性；独立样本假设不成立时使用独立轨迹/分组检验，不能把相关小时当独立试验。

优先追索作者 100 情景和 1000 次样本外测试的完整定义；精确复现缺数据时明确降级。
方法性测试至少 1000 条预先生成并冻结的独立日轨迹，统计口径与 A5 一致。
同时报告日前净成本、实时补救成本、总成本、备用未交付、联合室温违约、违约严重度。
允许连续多小时单向备用调用的压力测试，单列为外部压力情景。

**验收：**A1–A3、A5；风险结论保留 `supported / rejected / inconclusive`。
不能在成本较低但违约较高时说“全面优于”；不在测试集上重新调半径。
**论文目标：**第 5 章风险比较、图 5-8 的样本外成本及算法规模结果。

## 8. R7–R8：第 6 章，弹性要求与灾害恢复

### R7.1 先做可穷举的三层小系统

实现灾前机组/储能计划、有限易故障线路集合、灾后重构和失供能量。
将发生时间、持续时长、同时故障数、可再生出力情景、热网可用性、关键负荷集合显式输入。
独立标明“对故障最坏、对可再生场景加权”的量词。
供回水等效储能模型单独实现，并与详细热网回代结果比较。

**测试：**无故障退化、单故障手算、孤岛/连通性、辐射约束、断路后禁止输电、
灾前状态向灾后继承、时间窗口首末时刻、MWh 积分与电热失供分别统计。
对于 4 条脆弱线路、最多 2 条故障，按模型是否允许零故障明确枚举 11 或 10 种组合；
不能擅自删除较少故障的组合，除非已证明单调性。

### R7.2 嵌套 C&CG

处理 Q06：所有事件必须针对同一个当前灾前解校核通过；主问题改变后旧通过标志失效。
先用枚举作为故障对手基准，再实现内外层 C&CG。
记录每层上下界、故障集合、恢复解、阈值校核和预算；内部未认证时外层不宣布认证。

**验收：**A1–A2、A6；嵌套结果与微型枚举一致。
较大算例如果内层只有可行反例而无最坏情形上界，只能称发现风险或暂未发现，不能证明安全。
**图表：**F20 故障/恢复拓扑与供能，F21 内外层界及事件检查轨迹。

### R8：成本—保供曲线与资源消融

2026-09-20接续：[有损共同流量](ch06-lossy-flow.md)已有正向/停流详细参考与严格电池域24项冻结证据，
下一批优先在明确的这一控制域中推进阈值与资源对照；旧和式/无损结果保持。
这不表示完整有符号管流、恢复水力、连续节点或作者同规模算法已经认证。

复现经济基线、鲁棒方案和不同失供阈值方案；分别关掉热网灵活性、网络重构等能力。
改变阈值、同时故障数及可再生可用水平，每组固定其他条件。
阈值放松时，理论最优正常成本不应上升；数值异常先检查最优间隙，不能直接解释为物理反常。

**论文目标：**表 6-5 的成本/失供、表 6-7 的严格设定和无解边界，以及算法规模分析。

## 10. R10：最终交付及教学入口

**最终验收：**新克隆在无论文原件/无 Gurobi 许可时可运行开放微型测试和构建文档；
有许可且取得合法数据的环境可按固定命令复跑正式算例。
图表能够从保存的数值输出重新生成，重绘不启动优化。
一个从未读过项目的人能按“物理问题—手算例—代码—测试—图—边界”完成第一个小案例。
