# 复现验收协议与科学图表

版本：2026-09-16 / v0.1。配套[逐阶段计划](reproduction-plan.md)。
这里规定未来实验的判定方法，**不是已取得的验收结果**。
规范与阈值在正式运行前写入配置并冻结；修改须形成新决策、新配置和新运行，不能看到结果后放宽。

## 1. 每次运行必须交付什么

| 文件（拟定） | 内容 | 验收要点 |
| --- | --- | --- |
| `run.toml` | run ID、UTC、Git 提交/脏状态与差异哈希、Julia/包/求解器版本、系统资源、命令、线程、种子、配置/输入哈希 | 能定位本次实际执行的版本；脏工作区运行另存必要代码快照，不能只记 HEAD |
| `solver.log`、`trace.csv` | 各层状态、解/界、间隙、时间、迭代、停止原因 | 脱敏；局部目标、全局界、不可行证书分别记录 |
| `solution/` | 逐时设备、节点、支路、温度、状态、场景概率和支付等结构化输出 | 无解时无伪造零数组；单位、索引与配置一致 |
| `validation.toml` | A0–A6 的通过/失败/未判定、残差极值和位置 | 检查原式和采用的近似模型分别输出 |
| `comparison.csv` | 论文目标、出处、复现值、差异、基准口径与证据等级 | 不拼接不同输入、货币或版本 |
| `figures/` | 图、图源数据、图配置与说明 | 由已有输出重绘，不重新优化 |
| `summary.md` | 问题、方法、结果、失败、范围、下一步 | “运行成功”“数值一致”“科学主张被支持”分别结论 |

软件执行状态、数值可行性、算法认证、论文匹配和科学结论是独立字段。
正式报告保留 `input_missing`、`infeasible_certified`、`time_limit_with_incumbent`、
`time_limit_no_solution`、`numerical_failure`、`local_solution`、`gap_certified` 等原始事实。
状态转换表需用失败 fixture 测试，不能把异常转换成成功。

## 2. A0：一般软件测试与来源检查

- **单元测试：**手算设备、单位/基准换算、时间索引、成本分项、拓扑、概率和与输入拒绝。
- **集成测试：**小型网络建模—求解—提取—回代—落盘—重读；无解/超时/不受支持求解器的分支。
- **回归测试：**冻结的小系统指标和残差，不逐字比较可能因求解器变化而不同的日志。
- **变形测试：**单位换算后物理解不变；负荷/价格为零时正确退化；概率情景重排不改变结果。
- **来源检查：**输入完整且哈希匹配，派生规则可复跑；估读和假设值不能标作原始数据。
- **构建检查：**JuliaFormatter、Documenter 严格构建、导航及所有已开放 VS Code 任务的入口存在。

公共 CI 使用无许可小例，不能访问私有原件/大数据/许可。
Gurobi 测试在明确配置了许可的本地环境执行；CI 缺许可记 `not_run_license`，不等同于商业求解器测试通过。
现有骨架测试通过也不代表新增科学组件已覆盖。

## 3. A1：数值和物理可行性

验证器从保存的数值和输入重新计算原式，不只查询求解器的“可行”标志。
建模代码与验证公式保持可审查的独立实现，用手算例防止两者复制同一个错误。

以下为量纲统一后的初始门槛；每个量的参考尺度 `s` 在输入契约中固定，不能随残差调整：

| 量 | 项目门槛 | 必须记录 |
| --- | --- | --- |
| 电/热功率平衡与边界 | `abs_residual ≤ 1e-6 MW + 1e-6 × s_MW` | 最大值、节点、时段、场景 |
| 能量状态/积分 | `≤ 1e-6 MWh + 1e-6 × s_MWh` | 初末状态、损耗和时间步 |
| 流量守恒 | `≤ 1e-6 kg/s + 1e-6 × s_flow` | 供回水、方向和节点 |
| 温度等式或硬边界 | `≤ 1e-4 K` | 原模型与近似模型分别报告 |
| 电压/其他已无量纲化约束 | 归一化违约 `≤ 1e-6` | 基准电压、压力等参考量 |
| 整数变量 | 到最近整数距离 `≤ 1e-6` | 不先四舍五入再校验 |
| 情景概率、运输守恒 | 最大残差 `≤ 1e-8` | 权重和、非负性、距离预算 |
| 成本分项重算 | `≤ 1e-6 × max(1, abs(total_cost))` | 货币、价格尺度及全部分项 |

近似模型可能满足自身约束却不满足原始方程：应输出 `approximate_model_feasible` 与
`original_physics_failed`，不能合成一个绿色通过。
若某近似的误差可接受，必须在 R0 另订工程误差范围及理由；求解器容差不是物理误差许可。
对机会约束允许的室温违约，单列概率与幅度；其他硬安全约束仍逐样本检查。

## 4. A2：求解与算法正确性

### 可认证的小系统

选取有解析答案、可穷举整数决策/故障或可直接求解扩展式模型的案例。
同一数学模型的目标相对差不超过 `1e-4`；有有效界的最终相对间隙不超过 `1e-4`。
相对差分母采用 `max(1, abs(reference))`，并保留绝对差和目标单位。
不同模型之间的目标差不叫最优间隙。

分解算法必须核对：割的方向和前提、对偶符号、上/下界来源、非预见性、子问题失败传播。
连续凸子问题才按其适用条件取对偶；整数模型和非凸局部解不能自动提供 Benders 有效割。

### 局部与非凸算法

局部算法检查 A1、投影合法性、停止规则和初值敏感性；不强行要求它取得全球最优证明。
用至少 5 个预先固定初值报告可行率、最好/中位/最坏目标与耗时。
启发式黑盒对照使用 10 个固定种子，统一函数评估次数和最大时间；缺少界时最优间隙记缺失。

梯度有限差分检验在光滑段进行，至少用三个递减步长，目标相对误差门槛 `1e-3`；
在整数改变、时延分段或活跃集切换处先标识不可微性，不强行通过一个梯度断言。

### 计算预算与时间比较

| 层次 | 初始预算 | 到限行为 |
| --- | --- | --- |
| 能力预检 | 每个解析例 30 秒求解时间 | 非零退出，保留实际状态 |
| PR 微型科学测试 | 每例 60 秒，总 10 分钟 | 失败/未判定，不自动扩大规模 |
| 开发算例 | 每个实例最多 600 秒总墙钟，外层最多 200 轮 | 保留 incumbent、界和未完事件 |
| 正式论文对照 | 每个实例最多 10000 秒总墙钟 | 与论文时限口径并列，保留超时 |

全局预算覆盖嵌套调用，子求解器只取得剩余时间；不能每一层重新获得完整预算。
预热/JIT、建模、求解、验证、绘图分项计时；另报用户实际端到端时间。
确定性性能每配置重复 3 次报告中位数/范围；随机算法另用上述 10 种子。
主比较单线程、固定种子，同机相同输入。多线程扩展作为单独实验。
不把现代机器/新版求解器的时间差全部归因于论文算法。

## 5. A3：与论文的数值比较

以下阈值仅适用于已确认相同输入、模型解释、单位与统计口径的表格目标：

- 总成本、能量和主要规模指标：相对差 `≤ 0.1%`，另计原表末位舍入误差。
- 消纳率、供给率：绝对差 `≤ 0.1` 个百分点，不与百分比变化率混淆。
- 原始逐时数据可取得时：按预先约定幅度归一化的 RMSE `≤ 2%`，并检查峰值、积分和 A1。
- 扫描图估读：先报告读图分辨率/误差区间，不能机械套用原始时序门槛。
- 成本匹配但物理验证失败：论文匹配不足以通过研究验收。
- 存在原文冲突的目标：并列原表与文字，以决策后的目标为准，保留勘误。

多重最优允许不同轨迹；应比较目标、可行域、关键积分与机制，不能为了逐点一致额外加论文没有的约束。
原始数据不足时 `paper_match=blocked`，即使方法性测试很好也不升级为精确复现。
阈值未达到时报告差异，不用反向校准未知输入去匹配论文。

## 6. A4：分布式协调与收益分配

- 物理计划满足 A1，交易双方的能量账与网络账一致。
- 原始/对偶残差都需通过，使用归一化残差 `≤ 1e-4` 作为项目初始停止阈值，保留绝对量。
- 对可认证集中式基准，福利相对差 `≤ 0.1%` 为项目高精度目标。
- 分配后收益和应等于可分配总收益；每个主体不低于自己的分歧点，误差按 A1 成本尺度。
- 议价前提、权重和零/负协同剩余处理必须明确；失败个体不能被总福利改善掩盖。

论文表 4-8 的分布/集中福利差约 0.73%。忠实复现作者停止规则与达到本项目高精度目标
应作为两个配置、两项结果报告；不能修改算法后仍声称是原设置，也不能隐藏较大差值。

## 7. A5：样本外风险

**先冻结：**训练/验证/测试划分、场景聚类、半径、风险水平、种子和全部对照方案。
为各方案复用同一测试轨迹，记录配对成本差。
“联合违约”定义为一条完整测试轨迹中至少一个指定室温约束越界，
不是每个小时分别达到 95% 就算联合达到 95%。

对预设的独立同分布测试轨迹，样本数 `n`、联合违约数 `k`，采用单侧 95%
Clopper–Pearson 界。使用 Beta 分位数时：

```math
U = \begin{cases}1,&k=n,\\
Q_{\mathrm{Beta}(k+1,n-k)}(0.95),&k<n,\end{cases}
\qquad
L = \begin{cases}0,&k=0,\\
Q_{\mathrm{Beta}(k,n-k+1)}(0.05),&k>0.\end{cases}
```

- `U ≤ ε`：在声明的测试分布/采样前提下支持风险目标。
- `L > ε`：拒绝该风险目标。
- 其余：证据未定，不能因为点估计小于 ε 就称通过。

完整日轨迹内部可以相关，但轨迹之间必须符合上述采样前提；真实时序不满足时另设分组方案。
求解失败的测试轨迹不能从分母删除：单列未知数，并给出把未知全作违约的保守上界。
没有全部通过硬约束/交付检查的轨迹，不能标记为成功交付。
多个风险水平/多项正式结论需预先定义主要检验或进行多重比较处理。

成本同时报告均值、分位数、配对差及 95% 区间；需要 bootstrap 时固定重采样种子和次数。
尾部成本、室温越界幅度和备用未交付也必须列出。
本节是项目新增验证要求，不声称作者已经报告了全部这些统计量。

## 8. A6：灾害最坏情形认证

微型故障集合先完整枚举，每个恢复问题都可靠求解，与嵌套 C&CG 对照。
最大失供与阈值比较使用 A1 的能量容差。

- 若已认证的最坏失供上界不高于阈值，可支持该配置的模型内弹性要求。
- 若一个故障的最小失供已被证明大于阈值，可拒绝当前灾前计划。
- 若只有求解到限的恢复方案或未闭合的对手界，按实际界判断；不能仅凭一个较差恢复可行解就断言无可行恢复。
- 主问题更新后所有事件校核凭据失效；最终必须对应同一组灾前决策。
- 等效热储能模型通过不等于详细热网通过，后者单列回代检验和适用范围。

非预见性、修复过程、顺序故障如果不在论文模型内，就不添加到“原论文复现”配置中；
将其作为未来扩展的新协议，而不是暗中改变原目标。
