## 3. 模型审核时必须保留的区别

### 3.1 第 3 章：松弛、近似和局部求解

SCHPD 中的 McCormick 包络是对乘积约束的松弛；固定参考温度估计热损耗、
一阶差分近似温度动态、由主导入流确定混合温度则带有物理近似。
将这些处理组合在一起，不会自动产生原始物理模型的严格外松弛。

图 3-1 使用相邻迭代目标变化作为停止依据。停止并不等于取得全局最优性证书。
后续需分别检查原电网/水力关系的锥松弛残差、热功率乘积、传输延迟、混合温度、
逐时平衡及初末储能状态。不能只比较最终成本。

选型补充（PLAN-2026-09-16）：表 3-7（印刷 43 / PDF 60）的 NM-CHPD
是文献 [36] 的模型对照，表注说明采用 Gurobi NonConvex 直接求双线性问题。
不要将 NM 按缩写推断成 Nelder–Mead；具体模型定义仍需追索 [36]。

### 3.2 第 4 章：协作机制的前提

聚合商本地收益、运营商收益、全系统福利及内部支付是不同量。
必须核清福利统计时哪些支付相互抵消、网络费用和损耗怎样计入。
议价权重的设定、不同主体的分歧收益、合作稳定性与算法收敛也是不同问题。
本轮识别了论文的论证路线，尚未独立证明所有定理或审核非凸/整数条件下的适用性。

### 3.3 第 5 章：概率保证究竟指什么

以下只是将式（5-70）、（5-80）含义改写成便于审核的符号，不是完整模型转录：

```math
\inf_{P\in\mathcal P} P\{\text{所有指定室温约束同时满足}\}\ge 1-\varepsilon,
```

等价地，对补事件应有：

```math
\sup_{P\in\mathcal P} P\{\text{至少一项指定室温约束违反}\}\le\varepsilon.
```

这里的分布集合采用给定离散情景及概率运输距离构造。
它不会自动覆盖支持集之外所有新轨迹；半径选择、历史数据代表性及样本外测试方式均须核对。
式（5-70）具体约束室内温度，不能把它扩写为管网所有温度和安全边界都可放松。

求解还依赖市场下层的 KKT/强对偶适用条件、线性化所需的有效上下界及补救可行性。
论文使用关键场景筛选，并要求复查被省略场景的可行性；复现时须保留这一步。

### 3.4 第 6 章：最坏故障与期望失供不能混淆

式（6-52）–（6-53）可概括为：

```math
\max_{a\in\mathcal U_s}\;\min_{r\in\mathcal R(x,a)}
\sum_{\omega}\pi_\omega L_s(r_\omega)\le\overline L_s.
```

这是解释性记号：`x` 为灾前计划，`a` 为窗口 `s` 中的故障，`r` 为恢复决策，
`L` 为电热失供能量，`π` 为可再生出力情景概率。
最大化作用于规定的线路故障，求和意味着失供对可再生情景取期望。

边界包括同时故障数、指定脆弱线路、给定发生时刻/持续时间、热网仍可用以及简化恢复过程。
灾后使用供回水等效储能模型；聚合能量可行不自动证明每个节点的温度都可行。
第 7 章还改变了资源容量、关键负荷集合与时窗，不能和第 6 章阈值无条件互换。
