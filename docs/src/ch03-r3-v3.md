# R3物理可行性与停止判据

本批是项目核查版算法的继续完善，不改变论文原式和v1/v2历史判定。
阶段证据登记于仓库 `docs/agent/tasks/2026-09-17-r3-v3.md`。

## 1. 反例的三个层次

双源VF-CT已出现“固定流量SOCP通过，但原电网等式失败”；同模式的独立详细参考可行。
需分别检查模型实现、求解器数值状态和松弛本身的可行域差异。等价缩放改变求解状态首先是
数值/实现疑点，不单凭某次求解器INFEASIBLE就宣布整个模式无解。

审计接口 [`audit_r3_failure`](@ref) 从已核验运行提取必要阶段，参考只参与对比。
电网原等式与一阶展开为：

```math
g(x)=v_i\ell-P^2-Q^2=0,\qquad
g(x^k)+\ell^k\Delta v_i+v_i^k\Delta\ell-2P^k\Delta P-2Q^k\Delta Q=s^+-s^-.
\tag{R3-V3-1}
```

只有独立原关系检查通过，才能将候选标为物理可行。弹性量减小是恢复进展，不是成功调度。

### 冻结反例的首次审计

双源VF-CT历史运行中，首个、最低费及最小违反角色实际都指向阶段3914，费用457.90286018。
不能预设候选多样化一定能解决此例。同一流量重解：未缩放Clarabel返回OPTIMAL，等价缩放
Clarabel及Gurobi原等式模型返回INFEASIBLE；独立参考流量在三种形式下均有解。
这些状态首先属于数值/实现审计对象，不能单靠状态宣布整个模式不可行。

逐条原始变量见证显示，未缩放解在负荷端的固定热量及转换等式各分摊约2.7566e-6 MW误差。
进一步按固定源温、历史和流量，沿上游到下游独立回放供水：恢复尾段第6时段的热量
为0.3317085650 MW，而固定需求为0.3317030506 MW，差5.5144e-6 MW。此处尾段同时固定
流量、源温、负荷与回温，供水又受核心时段输运历史决定，存在很小但真实的等式不相容。
这是该固定流量的反例，并不证明更换流量后仍不可行；不修改尾段定义以消除此证据。

电网最大原等式残差仍为约4.1015e-4 pu。购电接近零与松弛电流同时出现，但不能据此
把整个失败解释为“用网损吸收多余电力”。热尾段冲突和电网锥松弛须分别处理。
诊断方法参照[求解器数值说明](https://docs.gurobi.com/projects/optimizer/en/current/concepts/numericguide/modelissues.html)
和[JuMP不可行诊断](https://jump.dev/JuMP.jl/stable/tutorials/getting_started/debugging/)。

## 2. 停止不等于同一件事

原页PDF54/印刷37的步骤2.b使用相邻目标绝对差与ε，并另设最大迭代次数。
当前已核查页未登记ε的数值；审计仅并列项目声明的1e-6、1e-4、1e-2费用单位阈值。
这些数值不能冒称作者设定，达到最大轮数也不等于驻点。

项目旧判据同时要求三次已接受相对费用变化不超过1e-6，及可信方向指标不超过1e-4。
使用 [`r3_stopping_evidence`](@ref) 重建每项布尔条件及局部KKT状态。
局部方向很小但不足三次小更新时，不伪造零步更新来补足计数；新增驻点核验将单独标记，
不会改写原outer_converged定义，更不等价于非凸全局最优证明。

双源SCHPD历史初值的第98轮：局部KKT通过，信赖域不活跃，方向1.7747e-8，预测改善
约-3.9355e-10；上一轮相对变化仍为2.1031e-6，因此连续小变化计数为零。此证据支持
实施独立驻点复核，尚不能替代三次原始变量和KKT的实际复核。

## 3. v3的流程与适用范围

显式使用 `algorithm=:r3_pg_checked_v3`。不传版本时仍使用v1；v2旧路径保留。
候选池按流量哈希去重，角色包括首个、最低费用、最小A1归一化违反和最近可行流量。
原等式调度按“最小违反、最低费用、最近、首次”顺序尝试，平局保留最早阶段。
已经通过物理A1的候选独立保留，末次求解失败不能覆盖它。

### 3.1 局部物理恢复

[`build_r3_physical_step`](@ref) 复用热耦合局部展开，增加式R3-V3-1的电网展开。
两类物理等式都允许双向弹性，容量、负荷、模式、原有锥和流量守恒是硬约束。
对MW、K、pu原始残差分别除以冻结的输入尺度，构造

```math
\Psi(x)=\sum_r\frac{|f_r(x)|}{\sigma_r},\qquad
\min_{\Delta x,s^+,s^-}\sum_r(s_r^++s_r^-)+0.01\|D\Delta x\|_2^2.
\tag{R3-V3-2}
```

热尺度与既有诊断相同；支路电尺度为
``\sigma_b=v_{\max}^2\ell_b^{\max}+2(P_{\max}/S_{\rm base})^2``。
`D`将流量、温度和支路等式涉及变量除以输入跨度；固定分量不参与。
初始半径0.1，拒绝后减半，下限1e-6，上限0.2；每步最多12次试探、最多20次接受更新。
真实/预测改善比至少0.1且真实残差下降才接受，比值至少0.75时允许扩大半径。
分段切换处以满足守恒的实际邻段求解检查，不使用任意一侧Taylor导数。

恢复使用的是原始变量方向。局部求解器若报告ALMOST_OPTIMAL或TIME_LIMIT，只在其原始
约束见证仍通过原门槛时允许检查候选；此时不宣称局部最优、不使用其对偶生成梯度。
所有候选都要重新计算原非线性关系与独立累计质量回放。方向的线性残差、真实残差及接受比
单独保存，重读时重新核查。原KKT阈值没有改变。

v3额外消去端口辅助热量，直接检查``c_pm(\tau^S-\tau^R)-H^{\rm demand}``，仍用既有MW门槛。
它防止两个分别合格的小残差同向叠加；该新增检查仅属于v3，历史版本判定不重写。
通过A1后固定该流量进行原等式费用优化。若此步失败，保留已通过A1的恢复候选，标明费用优化未完成；
“通过有限容差验收”不能写成精确方程有解或全局最优的证明。

### 3.2 独立局部驻点复核

只有光滑分段、局部KKT可信、信赖域不活跃、方向≤1e-4、预测改善绝对值≤1e-6才触发。
固定同一流量，另外两次重解子问题与局部问题；三次目标相对离散≤1e-6，且每次检查都通过，
才记录 `local_stationarity_checked`。原始乘子、原始变量、约束方向与局部见证保留，
重读时从仿射/锥模型独立重算KKT和对偶目标。复核不是接受更新，不增加小变化计数。

适用范围仅是当前光滑分段的松弛局部模型。它与 `outer_converged`、最终物理A1、
费用优化完成状态分别报告，不推出完整非凸问题驻点或全局收敛。

### 3.3 预算与复跑

完整运行仍为600秒：外层及驻点复核截止420秒；局部恢复最多120秒且不超过540秒；
最后候选调度合计最多60秒。所有建模计入，原等式候选共享剩余预算。

```julia
using PaperRebuild, Clarabel
c = load_r2_case("configs/r2/single-source.toml")
r = solve_r3_projected_gradient(c;
    algorithm=:r3_pg_checked_v3, initial_flow=[[1.0, 1.0, 1.0, 1.0]],
    convex_optimizer=Clarabel.Optimizer, budget_sec=60, max_iterations=10)
validate_r3_solution(c, r)
```

上例仅用开放求解器；需要最终原等式费用求解时通过 `optimizer` 传入本机Gurobi工厂。
正式入口 `scripts/experiment_r3_v3.jl` 读取 `configs/r3/v3-study.toml`，初值全部来自历史PG，
不读取直接详细参考解作为初值。消融只关闭对应功能，预算和输入不变。
