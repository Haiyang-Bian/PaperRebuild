## 1. 采用解释的证据链

| 疑点 | 理论依据与采用方程 | 假设及验证边界 |
| --- | --- | --- |
| R2-C01 符号 | 质量守恒：源端流出减流入为正，荷端相反；H=cp·m·(供温−回温)使用正幅值 | 固定方向径向网；供回水入流分别判定，不能以同一符号同时代表净注入和幅值 |
| R2-C02 损耗 | 沿管传热方程对温差给负指数衰减；WMM停留时间来自质量历史 | 采用预印本式29的解释，beta求和从滞后1起；不是断言论文期刊版完全相同 |
| R2-C03 包络 | 对w=mΔT写四面包络，再令H=(cp/10⁶)w | 四个角点及盒内包含检验可核实比热系数必须一致；这是有证据的单位修正 |
| R2-C04 能量 | 每侧E=ρALcp(T−Tmin)/3.6×10⁹；净热功率乘Δt小时得到MWh | 供回侧体积各计一次。Δt未印出可能表示1h约定；不单凭省略判笔误。平均管温是项目离散代理 |
| R2-C05 动态 | 单管有限体积守恒：ρALcp·ΔT/Δt+cp·m(Tout−Tin)+εL(Tref−Tamb)=0 | 有限体积模型不是WMM的等价改写，其空间均温近似须单独评估 |
| Q10 双线性 | 变流量与温差相乘仍非凸；项目增加有界McCormick包络 | 这是新增松弛，不是单纯纠错；SCHPD用于初始化，不作为最终物理调度 |

上述采用解释使方法验证可以继续；原式literal保留历史诊断，不等于所有补全都已有作者确认。
R3最终调度采用WMM热输运，不把SCHPD储热代理E额外强加给详细模型。

## 2. 为什么固定流量会得到凸子问题

由流量与历史计算α、β、出口质量比例和损耗系数后，出口温度是当前及历史入口温度的仿射组合。
本地端口流量由管网守恒确定，热功率和多入流混合也都成为温度的线性式。
设备约束为线性，电网和水力保留作者的锥松弛，因此本批固定流量SP应为连续SOCP；运行时检查实际约束类型。
输入为管道×时段的kg/s数组，不改原案例。未知历史不能用零补齐，非整步延迟不能取整。

```math
H=10^{-6}c_p\bar m(T^S-T^R),\qquad
T^{mix}=\frac{\sum_i\bar m_iT_i}{\sum_i\bar m_i}.
\tag{R3-T1}
```

手算：cp=4200 J/(kg K)，m=1 kg/s，供回温差40 K，得到0.168 MW。
若负荷为0.15 MW、回水313 K、供水上界363 K，则仅热交换边界就要求m≥0.7142857 kg/s。
0.5 kg/s虽在示例管道允许范围内，仍不能满足该负荷；传输历史和损耗还可能进一步限制流量。

## 3. 压力辅助变量重构证明

本模型中κ不进入成本，仅出现在0≤κ≤Φmax、ΔΦ≥κ和κ≥μm²。
因此当原解满足这些约束时，替换κ′=μm²≤κ，保留Φ与所有控制量，仍满足上述全部约束。

```math
0\le\kappa'=\mu m^2\le\kappa\le\Phi_{max},\qquad
\Delta\Phi\ge\kappa\ge\kappa'.
\tag{R3-T2}
```

实现：[`reconstruct_r3_pressure`](@ref)，测试R3 fixed schedule and reconstruction ch03-060。
函数返回副本，原始解与重构解分别验证。浮点误差仍按A1检查；若未来κ进入泵耗目标或其他下界，必须重审证明。
这不等于把ΔΦ≥κ改成等式，不包括泵曲线，也不证明电网锥松弛精确。
