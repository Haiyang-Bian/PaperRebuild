## 1. 采用解释的证据链

| 疑点 | 理论依据与采用方程 | 假设及验证边界 |
| --- | --- | --- |
| R2-C01 符号 | 质量守恒：源端流出减流入为正，荷端相反；H=cp·m·(供温−回温)使用正幅值 | 固定方向径向网；供回水入流分别判定，不能以同一符号同时代表净注入和幅值 |
| R2-C02 损耗 | 沿管传热方程对温差给负指数衰减；WMM停留时间来自质量历史 | 采用预印本式29的解释，beta求和从滞后1起；不是断言论文期刊版完全相同 |
| R2-C03 包络 | 对w=mΔT写四面包络，再令H=(cp/10⁶)w | 四个角点及盒内包含检验可核实比热系数必须一致；这是有证据的单位修正 |
| R2-C04 能量 | 每侧E=ρALcp(T−Tmin)/3.6×10⁹；净热功率乘Δt小时得到MWh | 供回侧体积各计一次。Δt未印出可能表示1h约定；不单凭省略判笔误。平均管温是项目离散代理 |
| R2-C05 动态 | 单管有限体积守恒：ρALcp·ΔT/Δt+cp·m(Tout−Tin)+εL(Tref−Tamb)=0 | 有限体积模型不是WMM的等价改写，其空间均温近似须单独评估 |
| Q10 双线性 | 变流量与温差相乘仍非凸；项目增加有界McCormick包络 | 这是新增松弛，不是单纯纠错；SCHPD用于初始化，不作为最终物理调度 |

上述采用解释使方法验证可以继续；原式literal保留历史诊断，不等于所有补全都已有作者确认。
R3最终调度采用WMM热输运，不把SCHPD储热代理E额外强加给详细模型。

## 2. 为什么固定流量会得到凸子问题

由流量与历史计算α、β、出口质量比例和损耗系数后，出口温度是当前及历史入口温度的仿射组合。
本地端口流量由管网守恒确定，热功率和多入流混合也都成为温度的线性式。
设备约束为线性，电网和水力保留作者的锥松弛，因此本批固定流量SP应为连续SOCP；运行时检查实际约束类型。
输入为管道×时段的kg/s数组，不改原案例。未知历史不能用零补齐，非整步延迟不能取整。

```math
H=10^{-6}c_p\bar m(T^S-T^R),\qquad
T^{mix}=\frac{\sum_i\bar m_iT_i}{\sum_i\bar m_i}.
\tag{R3-T1}
```

手算：cp=4200 J/(kg K)，m=1 kg/s，供回温差40 K，得到0.168 MW。
若负荷为0.15 MW、回水313 K、供水上界363 K，则仅热交换边界就要求m≥0.7142857 kg/s。
0.5 kg/s虽在示例管道允许范围内，仍不能满足该负荷；传输历史和损耗还可能进一步限制流量。

## 3. 压力辅助变量重构证明

本模型中κ不进入成本，仅出现在0≤κ≤Φmax、ΔΦ≥κ和κ≥μm²。
因此当原解满足这些约束时，替换κ′=μm²≤κ，保留Φ与所有控制量，仍满足上述全部约束。

```math
0\le\kappa'=\mu m^2\le\kappa\le\Phi_{max},\qquad
\Delta\Phi\ge\kappa\ge\kappa'.
\tag{R3-T2}
```

实现：[`reconstruct_r3_pressure`](@ref)，测试R3 fixed schedule and reconstruction ch03-060。
函数返回副本，原始解与重构解分别验证。浮点误差仍按A1检查；若未来κ进入泵耗目标或其他下界，必须重审证明。
这不等于把ΔΦ≥κ改成等式，不包括泵曲线，也不证明电网锥松弛精确。

## 4. 作者算法与本批边界

原算法见[式3-58至3-66](@ref ch03-algorithm-equations)。
作者固定m计算θ并求SP；不可行时最小化松弛量，再由灵敏度、割或投影更新m。
原文没有完整定义松弛的位置和尺度；3-59、3-64的变量记号以及3-61是否遗漏r对m的贡献须另行推导。
本批诊断与直接修正均标为项目方法，不使用未经证明的可行性割，也不宣称已复现梯度外层。

## 5. 项目诊断的范围与尺度

[`build_r3_subproblem`](@ref) 的 `mode=:diagnostic` 建立独立弹性问题。
只对式3-17的热功率、3-35/36的混合、3-33的输运和3-34的损耗加入双向松弛。
设备容量、固定负荷、电网、温度边界及固定流量均为硬约束。诊断不能通过删去负荷或提高容量获得成功。

```math
\min\sum_{i\in\mathcal R}(s_i^++s_i^-),\qquad
\frac{r_i(x;\bar m)}{a_i}=s_i^+-s_i^-,\quad s_i^+,s_i^-\ge0.
\tag{R3-D1}
```

其中热功率残差单位MW；混合残差先除总入流，输运先除当前流量，均化为K。
功率尺度取1 MW、总热设备容量及峰值热负荷三者最大值；温度尺度取1 K、供水和回水允许温差范围的最大值。
尺度完全由输入确定，保存在每行元数据中，不随求解结果改变。
诊断目标无量纲，不是运行费用；多个最优松弛分配可能存在，因此仅能定位当前诊断解的冲突分布。
松弛问题自身满足约束仍不表示可执行调度；硬约束不相容时，诊断也可以被证明不可行。
做法与[JuMP的罚松弛说明](https://jump.dev/JuMP.jl/stable/tutorials/getting_started/debugging/#Penalty-relaxation)一致，但松弛范围和尺度为项目定义。

## 6. 项目直接修正与最终验收

[`repair_r3_flow`](@ref) 用详细WMM恢复流量变量，并增加电网松弛前等式及κ等式：

```math
v_i\ell_{ij}=P_{ij}^2+Q_{ij}^2,\qquad \kappa_p=\mu_pm_p^2.
\tag{R3-D2}
```

```math
\min D_m=\sum_{p,t:m_p^{max}>m_p^{min}}
\frac{|m_{p,t}-m^0_{p,t}|}{m_p^{max}-m_p^{min}}.
\tag{R3-D3}
```

相等上下界的管道直接固定，不参与距离。绝对值由上图变量表示；有限预算的可行解，其上图目标可能略大于重算距离，两者分别保留。
修正阶段以距离为目标，其费用只是该可行解的附带值。通过独立物理检查后，再固定修正流量以费用为目标调度。
如果费用调度失败或超时，保留先前已核查的修正候选，标记“可行、成本优化未完成”。
费用最优仅针对该固定流量问题，不是全流量空间的全局成本最优；距离的下界不能作为成本下界。

[`solve_r3_feasibility`](@ref) 共用600秒截止时间，初始化、首个SP和诊断分别至多60秒，修正至多300秒。
只有电网原等式失败时，先保持流量求含原等式的详细问题；失败后才进入流量修正。
Gurobi使用[空间分支定界处理非线性约束](https://docs.gurobi.com/projects/optimizer/en/current/features/nonlinear.html)，记录实际终止状态和界，不预先保证预算内证明最优。
流程总计时包含阶段建模、求解和流程内验算；Julia进程启动、环境加载、保存后重验与绘图另计，不据此比较算法速度。

[`validate_r3_solution`](@ref) 从数值重算成本、质量守恒、热关系和松弛前等式，并使用独立累计质量回放核对WMM温度。
A1沿用既有门槛；弹性结果永远不能成为最终成功结果。完整流程、阶段数值和哈希由[`save_r3_run`](@ref)/[`read_r3_run`](@ref)保存与复核。
