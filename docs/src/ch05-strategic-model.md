# 连续报价怎样连接市场与风险补救

已有风险调度将价格作为输入。本节的r5_strategic_checked_v1让单个IES决定连续报价，
市场据此出清，再由同一成交量约束全部情景的实际调度。
仍采用合成输入、固定报价容量和有限支持风险；尚不能称为完整第5章数值复现。

## 1. 报价、成交和交付不是同一个量

购电报价表示IES愿意为多买一单位电支付多少；备用报价表示提供容量的报价。
它们不是最终成交价。市场在发电成本、网络和备用约束下决定成交及边际价格。
原PDF89的(5-32)给出报价界，(5-33)把内部日前购电/备用与市场成交连接。

输入由[`R5StrategicCase`](@ref)检查，构建由[`build_r5_strategic`](@ref)完成。
市场与补救的MW和时间步必须一致，不能因内部容量不足把市场成交悄悄缩小。
原式、采用解释和符号见[策略台账](ch05-strategic-model-equations.md)。

## 2. 怎样确保市场确实最优

下层为已有连续线性市场。原始约束、对偶可行、驻点和互补一起描述它的最优解。
连续报价只进入下层目标系数；其余发电报价和容量保持外生。

实现使用SOS1表达“非负乘子与剩余容量至少有一个为零”。没有给乘子任意截断上界。
Gurobi设置PreSOS1BigM=0关闭自动大M转换；数值容差仍须独立核查。
依据：[Gurobi SOS约束说明](https://docs.gurobi.com/projects/optimizer/en/current/concepts/modeling/constraints.html#sos-constraints)。

模型同时含原风险舒适二进制开关。只在固定全部互补及舒适分支时才称为LP。
固定分支求得的下界只能属于该分支，不能当成整个策略问题的下界。

## 3. 谁选择多个最优结果

本版显式采用optimistic_primal_dual：上层可以从下层最优成交及价格中选择对自己有利的组合。
这是一项项目假设。仅有KKT和支付恒等式不能证明现实市场也会采用该选择。

求解后固定报价、重新独立出清，只要求最优值一致并通过KKT。
独立求解器可能返回不同成交或不同价格，结果分别保存。
[`r5_market_settlement_range`](@ref)进一步固定全部成交，在对偶最优面寻找净支付两端，
用来区分报价效果和结算选择效果。该检查没有求解完整悲观双层问题。

上层选出的乘子存为optimized_KKT_variables；独立市场的MOI原始乘子另存。
不能把MIP中的优化变量伪装成求解器对偶。

## 4. 为什么不重复计算日前费用

[支付恒等式](ch05-strategic.md)计算真实日前净支出。内嵌风险模板的日前价格必须显式为零，
只提供设备和实时补救费用。总费用等于净支付加最坏补救费。
费用最坏分布、舒适开关最坏分布和实际越界事件最坏分布仍独立求解。

[`solve_r5_strategic`](@ref)的所有阶段共用截止时间；600秒中主求解最多540秒，
其余用于独立市场和运输见证。没有完成这些检查时，即使上层报告OPTIMAL也不记为费用认证完成。
[`validate_r5_strategic`](@ref)只读数值，重新核验市场、成交桥接、设备、热输运、室温风险及费用。

## 5. 两个可手算的对照

### 共同边际价格100

外部发电容量充足，能量及两种备用均有严格正的边际供给，三种价格固定为100。
此时连续报价不能改变边际价格，连通旧hard_zero物理输入的预期最优费为2.085美元。
该例检查新接口能否退化到已有固定价格基准，不用来证明市场操纵收益。

### 阶梯供给与自发电

外部低价机组容量0.2 MW、价格20；普通负荷0.1 MW；超过低价容量的外部电价为100。
IES总电需求0.142 MW，自发电价格130，备用显式为零。

固定购电报价100时，购电0.142 MW、费用14.2美元。
报价20且乐观选择边界成交0.1 MW时，剩余0.042 MW由自身发电，预期费用为

~~~math
20(0.1)+130(0.042)=7.46\ \mathrm{USD}.
\tag{R5-ST-E1}
~~~

这不是免费资源收益。外部与内部发电合计资源费分别为8.2和9.46美元，
因此私人费用减少可能伴随总资源费用增加。这里以合成发电报价作为资源成本代理；
正式实验分别报告这两个口径，
不能把这一合成机制扩大为现实市场结论。

## 6. 运行与证据

### 稀缺价格的负例

若唯一IES的上备用报价容量恰好等于系统需求0.08 MW，且没有外生稀缺价格规则，
对备用平衡乘子与IES报价上界乘子同时增加任意非负量，可保持驻点和对偶最优值。
发电侧备用容量为零时，其容量乘子可同步增加。这些变化不改变任何成交或实际交付，
却能把IES的备用收入持续增加。

~~~math
\sigma^U\leftarrow\sigma^U+a,\quad
\mu_{\mathrm{IES,bid}}^U\leftarrow\mu_{\mathrm{IES,bid}}^U+a,\quad
\mu_{\mathrm{G,bid}}^U\leftarrow\mu_{\mathrm{G,bid}}^U+a,\qquad
\Pi\leftarrow\Pi-0.08a,\quad a\ge0.
\tag{R5-ST-E2}
~~~

这说明有界报价不保证有界结算价。负例保留为原选择规则的边界，
不能通过隐式价格截断消除，也不能据此推断作者程序存在同样问题。

开发专项入口：

~~~powershell
julia +1.12.6 --startup-file=no --project=. scripts/test_r5_strategic.jl
~~~

冻结输入、14次正式策略运行、2次固定成交价格范围及只读图表见[正式结果](ch05-strategic-results.md)。
独立市场在全部12个有效运行中返回了不同成交量；相同市场最优值不能代替成交选择规则。
本批验证显式乐观模型，不认证现实市场必然执行同一调度。
