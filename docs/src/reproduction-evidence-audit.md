## 3. 接下来按什么顺序推进？

1. **交付可重算证据。** 先完成本批R1教学包与逐章入口，再逐包列明公开原值、冻结源码、
   许可/私有原件依赖和实际移位重验范围。仅有摘要或哈希的包不能声称可完整数值回放。
2. **补真正缺失的同口径实验。** 第3章原要求的PDN15/DHN10、PDN33/DHN32或明确完整的替代输入，
   与F07方法/规模/质量对照尚缺。NM-CHPD须按原文[36]及非凸双线性模型核查，不当作Nelder–Mead。
   第4章F13先固定可比较输入与主体拆分规则，并解决会阻断迭代的子块精度；不先绘“扩展性曲线”。
3. **补会改变机制结论的边界。** 第6章逐式和控制域、资源移除时序，第7章非零备用与完整故障域，
   分别使用先冻结的新协议。容量证书已经排除的当前目标保留，不重复搜索来制造成功。
4. **保留作者输入缺口。** 原输入、商软细节或解释仍不明时，给出可审查的采用推导和替代范围。
   它只限制相应数值匹配或主张，不阻断所有独立方法验证。

本页没有更改原计划、阈值或历史判定，也没有将作者展望中的未来扩展自动加入复现要求。
全文目标仍未完成；当前可交付的是多章方法/机制证据、明确负结果和可运行的入门闭环。
