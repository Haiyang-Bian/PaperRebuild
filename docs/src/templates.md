# 记录模板

复制适用模板，填入实际内容。未核实项写“待核实”，不填猜测。
以下为表单框架，不包含已完成科研结论。

## 任务记录

```text
任务 ID / 日期 / 负责人：
问题与范围 / 输入及来源：
已有用户改动：
操作 / 预期产物：
通过条件 / 停止条件：
实际检查及结果：
文档影响（路径或无影响理由）：
未解决问题 / 下一步入口 / 对应提交：
```

## 论文到实现映射

| 章节/页码/式表号 | 含义及单位 | 假设与来源 | 实现位置 | 验证方式 | 状态 |
| --- | --- | --- | --- | --- | --- |
| 待补充 | 待补充 | 待补充 | 待实现 | 待定义 | 未核查 |

## 实验记录

```text
运行 ID / 开始时间（含时区）：
研究问题 / 预先规定的接受阈值：
提交 SHA / 工作区未提交改动及留档：
Julia、锁文件哈希、求解器版本及许可要求：
输入逻辑路径、来源与 SHA-256：
配置路径及哈希 / 种子 / 线程数：
完整命令 / 机器与资源预算：
退出码 / 求解状态 / 耗时 / 停止原因：
输出目录 / 日志 / 产物哈希：
约束残差、目标分项及判定：
失败或限制 / 下一步：
```

| 待补充 | 待核实 | 未运行 | 运行前确定 | 待分析 | 未核查 |

## 决策记录

```text
决策 ID / 日期 / 状态：
背景与证据：

采用方案及原因：
受影响的假设、文件、实验和文档：
验证与撤回条件：
替代或关联的旧决策：
```
