# 第5章起步：联合机会约束的概率方向

## 核查结论

本次视读PDF92–94（印刷75–77），重新计算论文原件SHA256并与来源清单一致。
式(5-70)要求最坏分布下“所有指定室温约束同时满足”的概率不低于1-ε；
式(5-80)要求最坏分布下“至少一项违反”的概率不高于ε。两者通过补事件严格等价。

式(5-75)写成“全部违反”事件的下确界不高于1-ε，与上述两式不一致。
项目保留原式，采用(5-70)/(5-80)一致的含义。原文与采用解释保存在
台账文件docs/reading/ch05/probability-audit.toml。
这解除Q05对有限支持概率模型的语义阻断，不证明作者实际代码采用了哪一种表达。

## 补事件为何决定方向

令A表示一条完整随机轨迹上所有指定楼宇、时段及上下界都合格。
由概率公理，对任意非空分布集合：

~~~math
\inf_{\mathbb P\in\mathbb D}\mathbb P(A)
=1-\sup_{\mathbb P\in\mathbb D}\mathbb P(A^c),\qquad
A^c=\{\exists j:g_j(y_\omega)>0\}.
\tag{R5-Q05-1}
~~~

因此，“联合”要用至少一项越界定义失败。不能把每个小时分别取概率后求平均，
也不能把不同场景中的违约当成必须同时发生。

反例：两个等概率情景、两条舒适约束；情景1只违反第一条，情景2只违反第二条。
每个情景的“全部违反”都为假，故原(5-75)字面概率为0；但联合违约概率是1。
当ε=0.1时，两种表达会作出相反接受判断。ε=0.1是此解析例设置，不是作者实验参数。

## 有限支持的独立原对偶检查

固定情景及距离矩阵d，经验概率为p̂。Π的列表示经验来源、行表示扰动后目的：

~~~math
\max_{\Pi\ge0}\sum_{i,j}z_i\Pi_{ij},
\qquad\sum_i\Pi_{ij}=\hat p_j,\qquad
\sum_{i,j}d_{ij}\Pi_{ij}\le\rho.
\tag{R5-Q05-2}
~~~

从拉格朗日函数逐项收集Π系数，得到：

~~~math
\min_{\lambda\ge0,\nu\in\mathbb R^N}
\lambda\rho+\sum_j\hat p_j\nu_j,\qquad
\lambda d_{ij}+\nu_j\ge z_i.
\tag{R5-Q05-3}
~~~

列和对应等式，故ν自由；运输预算对应λ≥0。当z覆盖实际违约事件，
对偶值≤ε才给出该有限支持集合内的联合风险上界。这与原(5-77)至(5-79)的结构相符。
原式推导的个别指标/距离因子仍进入整章续核，不阻止由明确运输LP推导的版本。

例如经验违约概率0.1、两情景距离1，则最坏违约概率为min(1,0.1+ρ)。
ρ=0恢复经验分布，ρ=0.05得到0.15。等间距排列的三个情景的解析例、
排列不变性、全合格/全失败和原对偶残差由独立Julia脚本检查。

~~~powershell
julia +1.12.6 --startup-file=no --project=. scripts/audit_ch05_probability.jl
julia +1.12.6 --startup-file=no --project=. scripts/check_ch05_probability.jl
~~~
