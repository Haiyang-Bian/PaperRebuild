# R7：从管内温度到灾前显热

第6章式（6-90）需要事件开始前的管道热状态。本批新增`r7_plug_flow_reference_v1`，
用来核对整管温度分布、出入口热量和显热积分。它尚未接入完整灾前优化，也不认证灾后热量全部可回收。
原式与四条项目推导见[方程和符号](ch06-pipe-equations.md)。

## 出口温度为何不够？

考虑1000 kg水，其中左侧250 kg为340 K，右侧750 kg为300 K。
质量平均温度是310 K，右端出口却只有300 K。以300 K为参考、比热4200 J/(kg K)，
整管相对显热为0.0116667 MWh；若直接用出口温度乘总质量，会把它算成零。

式（6-90）的单一管温需要明确平均规则。这里根据热守恒按实际水质量积分，
同时显式保存参考温度；供、回水管各算一次。即使显热积分正确，出口温差、混合、流量和网络可达性
仍会限制实际可交付的热量，不能把这个数字直接全部交给负荷。

## 怎样保留输运记忆？

参考核将管道看成按空间顺序排列的水团。每一步按实际流过的质量移动温度分布，
新进入的水从上游插入，原有水从下游流出；流向反转时两端对调，原分布仍保留。
温度变化按水团在管内实际停留时间解析计算。即使停流，水也会与环境换热。

入口、环境和流量在单步内恒定；水不可压缩、比热和截面固定，传热系数沿管均匀。
不含管壁热容、轴向导热、水力或节点混合。这些是**项目参考的适用假设**。
流向反转能力只属于这个参考核，不改变现有恢复模型的方向边界。

输出的`outlet_mean_K`是整个时间步流出的水的平均温度；
`r7_pipe_temperature`查询的是某时刻、某空间位置的温度。停流时前者为`nothing`，不能补零。
原节点法和WMM有自己的离散散热近似；本批只在无损恒流退化下要求一致。

## Julia手算例

```jldoctest
julia> using PaperRebuild

julia> s = r7_pipe_state([250.0, 750.0], [340.0, 300.0]);

julia> r7_pipe_inventory(s; cp_J_kgK=4200.0, reference_K=300.0).mean_K
310.0

julia> r7_pipe_temperature(s, 1000.0)
300.0
```

900 kg初始300 K的水，入口330 K、流率1 kg/s、步长1小时且无损时，
这一小时流出900 kg旧水与2700 kg新水，出口平均温度322.5 K；
步末管内已全部换成330 K的水。这里的四分之一时段延迟无需四舍五入。

## 验证与下一步

损耗按每个水团的温差和留管时间独立积分，再核对进出能量与库存变化，
没有用能量平衡倒推损耗后自证。测试覆盖：非均匀初值、正向/反向/停流、整数与非整数延迟、
冷热环境、稳态指数衰减，以及同一边界下整步与两个半步的一致性。

下一步把正常网络计算所得流量、入口和初始管内状态传入参考核，
在事件前一时刻提取供回水库存，再与双水箱恢复模型比较。
完整正常调度、电池状态连接、节点混合及嵌套C&CG仍须完成。
